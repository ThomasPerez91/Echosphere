# Présentation desktop

**Statut : responsive validé ; détails UI orientatifs.**


Orientation : sidebar gauche pour les domaines, topbar pour contexte d'empire/univers et résumé,
contenu central pour la tâche, panneau droit contextuel seulement s'il améliore la lecture.
Les tableaux et comparaisons peuvent exploiter l'espace sans disperser une même décision.

Les indicateurs doivent distinguer état confirmé par le serveur, estimation d'interface et action
en attente. Une longue liste doit proposer filtres et tri, pas des dizaines de cartes décoratives.
Afficher coûts, contraintes et échéance avant validation. Les erreurs réseau conservent le contexte
et proposent une reprise explicite sans répéter une dépense incertaine.

Validation future : clavier complet, zoom 200 %, fenêtre étroite, redimensionnement et parcours de
dix minutes. Le dashboard cinématique n'est pas une contrainte pixel-perfect. La page actuelle
est volontairement un placeholder, sans sidebar prématurée.
