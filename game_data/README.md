# Paramètres de jeu futurs

Aucune valeur de gameplay n'est chargée à l'étape 0. Ce répertoire accueillera les coûts,
durées et coefficients versionnés séparément des règles métier. Format, schéma de validation
et politique de compatibilité des sauvegardes : questions ouvertes Q12 et Q13.
Une future simulation devra enregistrer la version des données et la seed utilisée.
